# W5S Github Actions

## Actions

* [w5s/cache-node](cache-node) - Setup cache for Node package managers
* [w5s/cache-playwright](cache-playwright) - Cache Playwright browsers
* [w5s/setup-asdf-tool](setup-asdf-tool) - Resolve and set an asdf tool version
* [w5s/setup-tools](setup-tools) - Setup tools from .tool-versions with official setup actions
* [w5s/setup-node-package-manager](setup-node-package-manager) - Setup Node package manager (Yarn, pnpm, Bun, npm)
* [w5s/setup](setup) - Setup all requirements
